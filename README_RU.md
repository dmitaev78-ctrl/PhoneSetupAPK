# Настройка телефона — Android-приложение

Исходный проект Android Studio для установки на Android 8.0 и новее.

## Возможности

- Два сценария для **нового** и **б/у** Android.
- Чек-листы для Android и iPhone (iPhone проверяется вручную; Android APK на iPhone не устанавливается).
- Сохранение выполненных шагов локально без аккаунта и интернета.
- Диагностика собственного Android: производитель, модель, версия ОС, патч безопасности, заряд, приблизительное свободное место.
- Переход в системные настройки Android.
- Быстрая настройка: тайм-аут экрана 2 минуты и включение автоповорота **после подтверждения пользователя и выдачи разрешения Android «Изменение системных настроек»**. Перед изменением значения сохраняются для отмены. Некоторые прошивки ограничивают эту возможность.
- Сохранение отчёта TXT и печать/экспорт PDF через системную службу печати.
- Нет разрешений на интернет, контакты или общий доступ к файлам телефона. Для двух изменений применяется особое разрешение `WRITE_SETTINGS`, выдаваемое пользователем вручную. Отчёт сохраняется через системный диалог.

## Как собрать APK на компьютере

1. Установите Android Studio (официальный сайт: https://developer.android.com/studio).
2. Распакуйте ZIP-архив и откройте папку `PhoneSetupAndroid` в Android Studio через **Open**.
3. Установите Android SDK Platform 35 при запросе. Для сборки используйте JDK 17, Android Gradle Plugin 8.7.3, Gradle 8.9. Зависимости должны быть загружены через интернет на компьютере.
4. В меню выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Установите на свой Android, подтвердив установку из выбранного источника в настройках устройства.

Альтернативно можно загрузить проект в собственный репозиторий GitHub и запустить workflow **Build Android APK** во вкладке Actions. Готовый debug APK загрузите из артефактов выполнения.

## Ограничения

- В этом архиве **нет готового APK**: в среде подготовки не установлен Android SDK, и не было доступа к скачиванию компонентов для сборки. Проект скомпонован, но не проверен сборкой и на настоящем устройстве.
- Android не позволяет обычным сторонним приложениям молча выполнять первоначальную настройку и менять все защищённые системные параметры. Приложение предоставляет план действий и открывает настройки, а не обходит защиту аккаунтов, PIN/FRP или блокировку iPhone.
- Автоматическая настройка отдельных параметров Android через USB доступна в отдельной программе для компьютера `phone_setup.py` из предыдущего архива.
- Сведения об аккумуляторе показывают заряд, не процент здоровья батареи. История ремонта, FRP, подлинность компонентов, сенсоры и связь требуют отдельной ручной проверки.
